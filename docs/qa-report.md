# QA прототипів (30.09.2026)

Скрипти: `tools/qa.py`, `tools/sweep.py`, `tools/interactions.py`, `tools/c3_quads.py`. Запуск локально через `http.server`, Chromium (Playwright). Форми не надсилались.

## Важливе застереження
Я не можу відкрити зображення й подивитись на них: інструмент повертає лише байти. Тому пункт «відкрити й переглянути скриншоти» виконано опосередковано:
- DOM-геометрія (позиції й перекриття блоків, вихід тексту за колонку);
- піксельна статистика скриншотів (домінантні кольори збігаються з палітрою; літери табло й скриншоти у вікні ключа справді відмальовані);
- грубі ASCII-карти композиції hero (розташування заголовка, ключа, табло, віяла).
Власнику варто переглянути `index.html` і скриншоти у `previews/` очима; це єдина перевірка, якої я не можу замінити.

Фокус: кільце 3 px, колір змінюється залежно від фону (малина, м'ята, хвоя; на темних секціях латунь/мандарин/м'ята).

## Взаємодії (Playwright)
- C1: клік по вікну ключа міняє скриншот і aria-label (ukg → prosvit); `details` розкривається; нахил за курсором лише на пристроях з мишею.
- C2: після завантаження 23 пластини (десктоп) / 22 (мобільний) складають «САЙТ ВІД ІДЕЇ ДО ЗАПУСКУ»; кнопка «Публікація» перегортає малий рядок на ПУБЛІКАЦІЯ, оновлює текст і `aria-pressed`; рядки робіт розкриваються.
  - `reduce`: текст одразу фінальний. Без reduce: на 0.35 с літери ще крутяться, на 3.8 с фінальні; кнопки клікабельні з першої миті.
  - Без JS заголовок лишається звичайним текстом, overflow немає.
- C3: клік по картці 4 оновлює підпис («Тренажер з історії України», посилання), `aria-pressed`; ←/→ переміщують фокус.

## Не перевірено / обмеження
- Справжні пристрої, Safari/Firefox (перевірено лише Chromium).
- Швидкість на слабких пристроях (прототипи легкі: шрифти ≈ 400 KB загалом локально, скриншоти WebP по 36–110 KB, без фреймворків).
- Зчитувачі екрана (семантика виставлена: skip-link, заголовки, aria-label, aria-pressed, aria-live; реального прослуховування не було).
- Emoji-квадрати: на самих прототипах емодзі немає; на скриншотах сайтів-замовників перевірено (див. `docs/skills.md`).
